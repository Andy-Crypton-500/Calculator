Calculator

A calculator project built using modern web technologies and Node.js.

Technologies:
HTML
CSS
JavaScript
Node.js
Express.js
Additional NPM modules


This website is definitely under development. In the math game, only the algebra and arithmetic game modes work while only simple versions of the calculus game work. The derivative and calculus graphing calculator does not work yet but most of the regular graphing calculator works. A basic version of a scientific calculator is also available. There may also be other bugs that may be present. The contract is also just for in case I ever publish the website.
